Scan retained summary windows to find unusual token use, concentrated users or sessions, tool errors and gaps in usage reporting.

Run it on your data

You need retained, complete summary windows from your collector, with enough earlier windows for a baseline (24 by default). Put them in ./summary-history. Keep the hash key and accounting configuration consistent, and replace app with your expected producer inventory.

Requires curl, gh, shasum and tar on Linux or macOS (amd64 or arm64). The installer downloads and verifies fleetdiff v0.7.0; analysis reads your local file. For a manual installation, see release verification.

curl -fsSLo install-fleetdiff.sh https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.7.0/scripts/install.sh
sh install-fleetdiff.sh v0.7.0 ./bin
./bin/fleetdiff scan ./summary-history --expected app --recent 2

Exit 3 means findings; 0 means none. No retained history yet? Configure summary export and retention with collector v0.3.2 / chart 0.3.4 first. This route needs history, not raw traces.

No data handy? Try the sample

Requires Git, curl, gh, shasum, tar, and Go 1.26.9 or later. Go generates synthetic inputs from the released tag; the scan runs with the verified v0.7.0 binary. No model API key or Docker is needed.

git clone --depth 1 --branch v0.7.0 https://github.com/llm-measurement/fleetdiff.git fleetdiff-anomalies
cd fleetdiff-anomalies
sh scripts/install.sh v0.7.0 ./release
GOWORK=off go run ./examples/scan --out ./synthetic-windows
./release/fleetdiff scan ./synthetic-windows --expected app --recent 2 \
  --as-of 2026-10-04T00:30:00Z

Reading the result

The example history produces two unusual windows. Tokens per attempt rise to 3.1 times the baseline; the following window has missing usage on 40% of attempts.

When a window reports missing usage, check the fields in a local capture: Do my LLM traces record token usage and user IDs?

Exit code 3 means findings were detected; 0 means none were found. The fixed date reproduces this sample. For current traffic, omit --as-of.

Keep watching your application

Retain enough exported windows for a baseline, then run the same command on that directory from a scheduled job. The scan guide explains thresholds, minimum history and persistence. The collector's Kubernetes summary guide covers durable storage and readback; use collector v0.3.2 with chart 0.3.4.
