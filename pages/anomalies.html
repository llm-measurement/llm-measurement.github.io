Scan retained summary windows to find unusual token use, concentrated users or sessions, tool errors and gaps in usage reporting.

Run it on your data

You need retained, complete summary windows from your collector, with enough earlier windows for a baseline (24 by default). Put them in ./summary-history. Keep the hash key and accounting configuration consistent, and replace app with your expected producer inventory.

Requires curl, gh, shasum and tar on Linux or macOS (amd64 or arm64). Install gh; it need not be signed in. The installer downloads and verifies fleetdiff v0.11.0; analysis reads your local file. For a manual installation, see release verification.

curl -fsSLo install-fleetdiff.sh https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.11.0/scripts/install.sh
sh install-fleetdiff.sh v0.11.0 ./bin
./bin/fleetdiff scan ./summary-history --expected app --recent 2

Exit 3 means findings; 0 means none. No retained history yet? Configure summary export and retention with collector v0.6.0 / chart 0.6.0 first. The guide covers durable storage and readback. This route needs history, not raw traces.

To keep watching, run the command on retained windows from a scheduled job. For current traffic, omit --as-of; the scan guide explains thresholds, minimum history and persistence.

No data handy? Try the sample

Requires curl, gh, shasum, tar, and Go 1.26.9 or later. Go generates synthetic inputs from the released tag; the scan runs with the verified v0.11.0 binary. No model API key or Docker is needed.

curl -fsSLo fleetdiff-source.tar.gz https://github.com/llm-measurement/fleetdiff/archive/refs/tags/v0.11.0.tar.gz
tar -xzf fleetdiff-source.tar.gz
cd fleetdiff-0.11.0
sh scripts/install.sh v0.11.0 ./release
GOWORK=off go run ./examples/scan --out ./synthetic-windows
./release/fleetdiff scan ./synthetic-windows --expected app --recent 2 \
  --as-of 2026-10-04T00:30:00Z

The fixed --as-of date reproduces this sample.
