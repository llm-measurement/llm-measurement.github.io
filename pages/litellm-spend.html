Compare two periods of LiteLLM spend logs to see which models and keys drove a change, and which records have incomplete usage.

Run it on your data

A request-level LiteLLM export such as spend.csv, or read-only access to the proxy’s Postgres database to create one. Use the read-only export recipe; the Usage dashboard’s daily aggregate is a different format.

Requires curl, gh, shasum and tar on Linux or macOS (amd64 or arm64). The installer downloads and verifies fleetdiff v0.7.0; analysis reads your local file. For a manual installation, see release verification.

curl -fsSLo install-fleetdiff.sh https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.7.0/scripts/install.sh
sh install-fleetdiff.sh v0.7.0 ./bin
./bin/fleetdiff investigate --litellm-spend ./spend.csv --group-by key

Export 16 days for the default seven-day comparison. For shorter exports, select explicit --before-period and --after-period dates. Choose --group-by team, user, end-user or session for another view.

No data handy? Try the sample

Requires Git, curl, gh, shasum and tar. Linux or macOS, amd64 or arm64. The sample uses the released binary and a synthetic CSV.

git clone --depth 1 --branch v0.7.0 https://github.com/llm-measurement/fleetdiff.git fleetdiff-litellm-spend
cd fleetdiff-litellm-spend
sh scripts/install.sh v0.7.0 ./release
./release/fleetdiff investigate --litellm-spend examples/litellm-spend/synthetic.csv \
  --before-period 2026-10-07 --after-period 2026-10-08

Reading the result

Export from LiteLLM Postgres

Requires psql and approved read-only access configured as the PostgreSQL service litellm_readonly. Choose UTC bounds in START_UTC and END_UTC (RFC3339, for example 2026-09-23T00:00:00Z and 2026-10-09T00:00:00Z). These paths are verified against LiteLLM v1.104.0. Review the projection before using a different writer version.

umask 077
curl -fsSLo export.sql https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.7.0/examples/litellm-spend/export.sql
export_dir=$(mktemp -d ./litellm-export.XXXXXX)
psql 'service=litellm_readonly' -Xq -v ON_ERROR_STOP=1 \
  -v start_utc="${START_UTC:?set the export start in UTC}" \
  -v end_utc="${END_UTC:?set the export end in UTC}" \
  -v csv_file="$export_dir/spend.csv" -f export.sql \
  >"$export_dir/private-psql.out" 2>"$export_dir/private-psql.err"
./bin/fleetdiff investigate --litellm-spend "$export_dir/spend.csv" --group-by key

The transaction is read-only and excludes prompts, responses and whole metadata objects. It includes identities needed for local grouping, so keep the export and database diagnostics private. Use explicit comparison periods for sparse or shorter exports.

In this synthetic example, recorded tokens double from 8,000 to 16,000, two keys account for the increase, and the report identifies zero-only and failed records to review.
