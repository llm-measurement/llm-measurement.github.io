Compare two periods of LiteLLM spend logs to see which models and keys drove a change, and which records have incomplete usage.

Run it on your data

Start with read-only access to LiteLLM's Postgres database, or an existing request-level CSV, JSON or JSONL export. If you already have an export, skip step 1 and use its path in step 3. The Usage dashboard's daily aggregate is a different format.

1. Export from LiteLLM Postgres

Requires psql and approved read-only access configured as the PostgreSQL service litellm_readonly. Choose 16 days of UTC bounds in START_UTC and END_UTC (RFC3339, for example 2026-09-23T00:00:00Z and 2026-10-09T00:00:00Z). These paths are verified against LiteLLM v1.104.0. Review the projection before using a different writer version. Run the following in a directory without an existing litellm-export folder.

umask 077
curl -fsSLo export.sql https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.8.0/examples/litellm-spend/export.sql
mkdir ./litellm-export
psql 'service=litellm_readonly' -Xq -v ON_ERROR_STOP=1 \
  -v start_utc="${START_UTC:?set the export start in UTC}" \
  -v end_utc="${END_UTC:?set the export end in UTC}" \
  -v csv_file='./litellm-export/spend.csv' -f export.sql \
  >./litellm-export/private-psql.out 2>./litellm-export/private-psql.err
printf 'Exported request-level rows to ./litellm-export/spend.csv\n'

The transaction is read-only and excludes prompts, responses and whole metadata objects. It includes identities needed for local grouping, so keep the export and database diagnostics private.

2. Install fleetdiff

Requires curl, gh, shasum and tar on Linux or macOS (amd64 or arm64). Install gh; it need not be signed in. The installer downloads and verifies fleetdiff v0.8.0. For a manual installation, see release verification.

curl -fsSLo install-fleetdiff.sh https://raw.githubusercontent.com/llm-measurement/fleetdiff/v0.8.0/scripts/install.sh
sh install-fleetdiff.sh v0.8.0 ./bin

3. Investigate the export

Analysis reads your local file. Use the export from step 1, or replace its path with your existing request-level export.

./bin/fleetdiff investigate --litellm-spend ./litellm-export/spend.csv --group-by key

The default compares two complete seven-day periods. For sparse or shorter exports, select explicit --before-period and --after-period dates. Choose --group-by team, user, end-user or session for another view.

The export, install and investigate path and spend export guide cover fields and period choices. For continuous metrics and summary windows, use the collector's LiteLLM recipe.

What you'll see

Example output from the synthetic sample below; your values will reflect your input.

Recorded tokens doubled (8,000 -> 16,000).
model-1 accounts for 100% of the net recorded increase (+8,000 tokens).
Logged model requests: 8 -> 12.

Recorded tokens doubled, while logged model requests grew from eight to twelve. fleetdiff separates model-by-model usage changes from contributor rankings and completeness.

Who drove the increase?
  key-1: 5,000 -> 10,000 tokens; change +5,000.
  key-2: 1,000 -> 4,000 tokens; change +3,000.
  key-3: 2,000 -> 2,000 tokens; change +0.
  2 leading tracked keys account for 100% of the net recorded increase.
  Attributed tokens: 8,000 -> 16,000.

Two keys account for the increase. The contributor section uses local aliases for the keys.

How complete is the export?
  Records needing usage review (categories may overlap): 2 -> 4.
  Zero-only records, origin unknown: 2 -> 4.
  Failed records (overlap usage categories): 1 -> 2.

The completeness section points to zero-only and failed records worth checking in LiteLLM. To check usage and identity fields in your telemetry, see Do my LLM traces record token usage and user IDs?

No data handy? Try the sample

Requires Git, curl, gh, shasum and tar. Linux or macOS, amd64 or arm64. The sample uses the released binary and a synthetic CSV.

git clone --depth 1 --branch v0.8.0 https://github.com/llm-measurement/fleetdiff.git fleetdiff-litellm-spend
cd fleetdiff-litellm-spend
sh scripts/install.sh v0.8.0 ./release
./release/fleetdiff investigate --litellm-spend examples/litellm-spend/synthetic.csv \
  --before-period 2026-10-07 --after-period 2026-10-08

Source and reproduction: released synthetic CSV and accounting and privacy checks. Verification record.
