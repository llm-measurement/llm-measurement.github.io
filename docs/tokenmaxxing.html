Who is tokenmaxxing? Find your heaviest AI token users

Rank people by reported token volume from keyed IDs, and see how much of your usage a few people account for. A short, bounded ranking answers "who are our heaviest AI users?" without keeping a raw table of every employee's usage.

Rank one synthetic week

Requires Python 3.11 or later. Installation downloads the pinned release from PyPI; ranking runs locally.

python3 -m venv .venv
.venv/bin/python -m pip install --no-cache-dir llm-sketchkit==0.2.2
.venv/bin/python - <<'PY'
import random
from llm_sketchkit import USER_V1, canonicalize_text_v1, frequentitems, hash64, hllpp
from llm_sketchkit.hash import Secret

secret = Secret(b"tokenmaxxing-synthetic-example-key-2026")  # public demo key; use your protected key in practice
ranking = frequentitems.Sketch("small", USER_V1)
people = hllpp.new("small", USER_V1)
total = 0

# One synthetic week: 60 people with heavy-tailed session sizes.
rng = random.Random(2026)
for n in range(60):
    digest = hash64(secret, USER_V1, canonicalize_text_v1(f"person-{n:02d}@example.com"))
    people.add_hash(digest)
    for _ in range(rng.randint(3, 25)):
        tokens = int(20_000 * rng.paretovariate(1.2))
        ranking.add_hash(digest, tokens)
        total += tokens

items = ranking.frequent_items(frequentitems.NO_FALSE_NEGATIVES)
top = sorted(items, key=lambda i: i.lower_bound, reverse=True)[:5]
print(f"People using AI this week: {people.estimate():.0f}")
print(f"Total reported tokens: {total:,}")
print("Heaviest users (keyed; only the key holder can look them up):")
for rank, item in enumerate(top, 1):
    exact = item.lower_bound == item.upper_bound
    amount = f"{item.lower_bound:,}" if exact else f"{item.lower_bound:,} to {item.upper_bound:,}"
    print(f"  #{rank}: {amount} tokens")
low = sum(i.lower_bound for i in top) / total
high = min(1.0, sum(i.upper_bound for i in top) / total)
share = f"{low:.0%}" if f"{low:.0%}" == f"{high:.0%}" else f"{low:.0%} to {high:.0%}"
print(f"The top 5 of {people.estimate():.0f} people account for {share} of all tokens.")

The top 5 of 60 people account for 43% of all tokens.

In this synthetic week, 5 of 60 people account for 43% of reported tokens. The ranking holds keyed values, not names, so it can be shared with a manager or a finance team as it is. Whoever holds the key can look up a person by hashing a known ID.

Teams and budgets

Teams are few, so count them exactly; a few dozen budget lines don't need a sketch. Use the keyed ranking for people, where the list is long and names are sensitive. To see whether a jump came from more people or from a few heavier ones, compare two weeks: Which user is driving my LLM token spike?

From your gateway or collector

If your usage flows through an OpenTelemetry Collector, the released connector keeps the same keyed, token-weighted ranking continuously, in snapshot logs and summary files, without user labels on your metrics. See per-user metrics and the ranking configuration.
